# b2b-miles-booking

> Emitir passagens com milhas consultando fornecedores externos lentos, evitando overbooking e timeouts na experiência.

## Problema

Emitir passagens com milhas consultando fornecedores externos lentos, evitando overbooking e timeouts na experiência.

## Solução

Orquestração assíncrona com controle de concorrência, timeout por provedor e normalização de respostas heterogêneas. TypeScript/Node.js com PostgreSQL e mocks de fornecedores via Docker Compose.

## Stack

- TypeScript
- Node.js
- Docker
- PostgreSQL
